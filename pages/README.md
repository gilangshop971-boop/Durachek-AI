## Tentang Proyek

**DuraCheck AI** membantu junior engineer bekerja lebih akurat dengan panduan teknis berbasis AI sesuai standar industri internasional.

## Fitur

- 💬 **Tanya AI** — Chat seputar toleransi, GD&T, surface finish
- ✅ **Checklist Review** — 35+ item sebelum gambar di-approve
- 📚 **Referensi Standar** — API 610, ISO 2768, ASME Y14.5, ISO 1302
- 📱 **PWA** — Install di HP seperti app biasa

## Deploy

1. Clone repo ini
2. Tambahkan environment variable: `ANTHROPIC_API_KEY`
3. Deploy ke Vercel
